# 单导师 AI 评价接口预留（v0.3 设计占位）

> 用户 2026-10-01 指令："对于单个老师，最后还要有一段 AI 的评价，现在先把接口留着。"

## 接口设计（数据层预留）

roster_all / 展示层 schema 新增字段位（本轮**不实现生成**，仅占位）：

```json
{
  "ai_summary": {
    "generated": false,
    "model": null,
    "generated_at": null,
    "content": null,
    "sources": ["reviews", "profile", "public_pages"],
    "disclaimer": "AI 生成摘要，仅供参考，非人工审核结论"
  }
}
```

## 生成原则（实现时的约束，先立规矩）

1. **输入可溯源**：仅基于三类已入库数据生成——评价库条目（含时间衰减权重）、方向画像（profile）、公开页面快照；每句话可回溯到来源记录
2. **水印强制**：内容前置"AI 生成"标识 + 免责声明；与真人评价视觉区隔
3. **红线继承**：不输出"建议报/不建议报"式裁决（advisor-research 同款红线）；负面信息只呈现证据不加工定性；涉及师德类仅链接官方通报
4. **无评价导师的处理**：零评价导师的 AI 摘要仅基于画像与公开信息（方向/职称/产出），明确标注"该导师暂无学生评价"
5. **支持"掺杂私货"**（用户原话）：预留人工 override 通道 `ai_summary.human_note`——用户可对特定导师附加人工撰写内容，与 AI 生成内容分栏展示

## 建议实现时机

评价平台（轨道 A）最小可用站时，作为导师详情页的默认模块；生成管线挂 advisor-research skill 的报告生成器复用。
