## ⚠️ 高危：数据投毒（置顶）

| 现象 | 判别 | 解法 | 来源 |
|---|---|---|---|
| **webReader `_result_summary` 压缩层伪造名录（数据投毒）** | 凭空造名、混入外校真人（颉满刚=西北师大被造入兰大）、给占位错误填仿真值、伪造分页（"共114名分3页"实测 404）、字段跨运行漂移 | 判别：renderer 元数据缺失 / **同 URL 两次运行返回不相交人名集**（必有一假，这是投毒信号而非缓存噪声）；仲裁：搜索引擎索引快照核对 + 逐条对照 source_urls 原始页；**webReader 类通道只信原始 DOM 不信摘要层，凡经它的数据必须抽审** | [LZU 兰大，2026-10-01 击退并留痕 raw/verification_log.txt] |

## 数据完整性（最高优先级——页面存在且 API 正常 ≠ 数据完整）

| 现象 | 判别 | 解法 | 来源 |
|---|---|---|---|
| **名录页"存在≠完整"，CMS API 也为不全背书** | 名录条数远小于学院自称规模（浙大计算机名录 139 vs 自称 224，吴飞/赵洲/李玺等核心教授全员缺席） | 名录条数与学院规模明显失衡时**必须找第二来源**交叉补（浙大用《导师资格目录》xlsx 补 102 人）；"页面正常+API 正常"不构成完整性证据 | [ZJU 浙大] |
| **新设学院不进母站院系目录、搜索引擎也不给官网** | 知名教授"集体失踪"于现有名录 | 先怀疑机构重组（浙大 2025-07 新设 ai.zju.edu.cn 即如此），反推搜索学院新域名；不纳入则 AI 覆盖严重失真 | [ZJU 浙大] |
| 0854 专硕企业导师（周靖人/任小枫/叶杰平类）在导师资格册但不在师资页 | 导师册人数 >> 师资页 | 单列 external 文件待人工归类，不入主名录 | [ZJU 浙大] |

## 反爬与访问障碍

| 现象 | 判别 | 解法 | 来源 |
|---|---|---|---|
| 全站 412 Precondition Failed（教师主页系统类站点） | 状态码 412，任何路径都一样 | JS cookie 挑战型 WAF，无浏览器环境**不绕过**（红线）。走降级链：学院师资页职称邻接文本 → 学院英文站 Faculty 页 → 领导页/新闻点名 → 搜索引擎逐人核实，并把名字来源记 `name_source` 审计字段 | [NWPU] |
| **裸域无 A 记录、www 子域才可解析** | 直接连 000/DNS 查无 IP | 探路时裸域与 `www.` 前缀**两种形式都试**（清华 thss/insc 即如此） | [THU] |
| **域名直觉不可靠** | 猜的子域不通或属于别的单位 | 从**母站院系列表页**提取真实域名（北大智能学院是 sai.pku.edu.cn；哈工大电信学院是 seie.hit.edu.cn，主站院系目录还是 JS 渲染的）；勿猜 | [PKU/HIT] |
| **同名机构 URI 陷阱** | ai.pku.edu.cn 实为李文新组实验室自站点 | 以页面 title + 版权栏 + 母站院系列表**三重验证**机构层级（实验室级 ≠ 学院级名录） | [PKU] |
| 搜索引擎批量查询触发验证码/JS 壳页 | 百度/搜狗连续查询后返回壳页 | 放弃本地批量搜索，改内置搜索能力**逐人**核实（每人 1-2 次） | [NWPU] |
| 403 / 跳转验证页 | 状态码或 URL 变了 | 检查 UA；降频到 5s+；换入口（www 与子域防护常常不同） | 预写 |
| 拦截页返回 200 伪装正常 | 目标字段为空但页面结构在 | 成功判定必须校验"目标字段真的存在" | 预写 |
| 429 / 瞬时 502 | 状态码 | 立即停或重试一次；间隔翻倍；`done.json` 保证续跑不重抓 | 预写+[HIT 验证 502 重试有效] |

## 页面形态与数据源定位

| 现象 | 判别 | 解法 | 来源 |
|---|---|---|---|
| **Gpower CMS 栏目 index.htm 是 JS 壳** | 响应体仅 1-2KB，含 `window.location.href='xxx'` | 解析跳转目标跟进一次（北大 ic/ss/icst 三站同款） | [PKU] |
| **名录数据整块藏在页面 JS 变量数组里** | HTML 正文无姓名 | grep `showTitle` / `=\s*\[` 定位，`json.JSONDecoder().raw_decode` 解析（清华 EE 系 qh_data ×22 组 152 条，自带方向+主页，比 HTML 解析稳）；注意占位脏数据（asfsf@asdfs.com）过滤 | [THU] |
| **Sudy WP CMS 隐藏 API**（2024-25 新站群常见） | 列表页正文是空 `<li>` + ajax-loader，静态抓 0 条 | 真数据在 `POST /_wp3services/generalQuery?queryObj=teacherHome|articles`，参数（siteId/columnId/returnInfos）藏在前端模板 JS `/_upload/tpl/**/js/*.js`，grep `generalQuery` 即得；复旦一次逆向三站复用 | [FUDAN] |
| **字段藏在 HTML 注释里** | 页面渲染可见但源码 grep 不到 | 源码与渲染对照；被 `<!-- -->` 包裹的字段按"站方隐藏中"处理，只采未注释字段（北大 ic 学院邮箱整段被注释） | [PKU] |
| **同一名录多视图**（按拼音/单位/职称） | 同站多个列表入口 | **比对各视图总条数再选**，不能默认"按职称"最全（复旦 fit 按职称版仅 27 人、按单位版 194 人） | [FUDAN] |
| 倒序编号分页（第 1 页链到 /4.htm → /3.htm…） | 页码 URL 与自然序相反 | **翻页一律跟随"下页"链接链式走，禁止页码算术 +1** | [NWPU，PKU/HIT/FUDAN 再验证] |
| **假分页（Sudy WP）**：list1/2/3.htm 静态内容完全相同且每页含全部分组，"下一页"循环链接 | 相邻页内容签名（哈希/条目数）相同 | 相同则只解析一页——照"跟下一页"铁律走会三倍重复（USTC 首轮出 348 条假数据） | [USTC 中科大] |
| **尾页"下一页"= `javascript:void(0)`** | urljoin 把它当带 scheme 的绝对 URL 原样返回 | urljoin 前先识别终止符（void(0)/#），否则脚本崩溃、done.json 误标失败 | [USTC 中科大] |
| **带 style 等属性的分组标题漏检** | `<div class="title" style="...">外聘博导` 被精确正则漏掉 | 分组标题正则**允许任意属性**；用条目链接的栏目 ID 交叉校验分组边界（17 名外聘博导曾静默并入"副高"） | [USTC 中科大] |
| 同校不同学院名录形态完全不同 | 单页大表/按系分页/按职称分栏/照片墙并存 | 阶段 0 逐学院探路，不套用第一个学院形态 | [NWPU] |
| 翻页参数藏在 POST 表单 | URL 不变 | 第一页 HTML 的 `<form>` 就是答案 | 预写 |
| 数据是整页 JPG 图片（研招目录类） | vsb_pdf_image_data 或大图占位 | **先用多模态图像分析**（远程 URL 喂 `mcp__4_5v_mcp__analyze_image`，已验证可用），要求转写全部文字；读不了再放弃 | [NWPU + 多模态验证] |
| 邮箱/名单做成小图片（防爬） | 页面 grep 不到文本 | 多模态逐图转写；图片 URL 就在 `<img src>` 直传 | [新增] |
| **首页导航折叠子栏目** | ccst 师资首页只露 3 栏 41 人，完整 8 子栏目（教授/副教授/讲师/鼎新/教研室）只在内页侧栏——简介自述 198 人 vs 首轮可见 41 人 | 规模数字与栏目条数失衡时**抓内页侧栏取全栏目树**（完整性第六防线） | [JLU 吉大] |
| **"副教授"含"教授"子串 + 纯文本分组 + 非链接名字并存** | rfind 最近标签法判职称几乎全错（副教授仅 5/48 正确） | 顺序标记替换法：锚点替换为 `\x01名\x02url\x03` 定长标记再按组标签 token 切状态机 | [JLU 吉大] |
