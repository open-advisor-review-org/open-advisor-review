# 导师评价维度体系 v0.1

> 状态：草案，待讨论定稿。前 7 个维度继承自原"导师评价网"的成熟模板（2014–2020，28k 条评价验证过的结构），其余为本项目扩展。
> 设计原则：**硬信号优先于观点、计数优先于叙事、可交叉验证优先于孤证**。

## 一、通用维度（继承七维度）

| # | 维度 | slug | 采集形式 | 呈现形式 |
|---|------|------|---------|---------|
| 1 | 导师辨识特征 | `identification` | 自由文本（消歧用：职称/方向/特征） | 原文 |
| 2 | 学术水平 | `academics` | 自由文本 + 1–5 分 | 文本 + 维度分 |
| 3 | 科研经费 | `funding` | 自由文本 + 1–5 分 | 文本 + 维度分 |
| 4 | 学生补助 | `stipend` | **数值（元/月）** + 自由文本 | 补助区间 + 文本 |
| 5 | 师生关系 | `relationship` | 自由文本 + 1–5 分 | 文本 + 维度分 |
| 6 | 工作时间 | `workload` | 勾选（弹性/打卡/大小周…）+ 自由文本 | 勾选统计 + 文本 |
| 7 | 学生前途 | `outcome` | 自由文本 + 1–5 分 | 文本 + 维度分 |

改进（相对原版）：补助改为**数值采集**（跨导师可比）；工作时间改为**勾选优先**（防主观渲染）。

## 三、学生流向硬信号（延毕 / 退学 / 转导师）

定位：**预警价值最高、最难被刷评污染**的维度。

- 采集：匿名勾选 + 计数——"你了解的同门中：延毕 __ 人、中途退学 __ 人、转出导师 __ 人、被劝退 __ 人"。**不设自由文本个案指控**（法律风险控制）。
- 呈现：群体统计，如"近 5 届评价者报告延毕 X 人 / 转导师 Y 人"，随评价时间衰减加权。
- 交叉验证（公开信息，不依赖评价者）：
  - 研究生院**毕业/学位授予公示名单** vs 历年**招生名单** → 实际毕业缺口；
  - 导师主页历年招生数、在读学生名单变动。
- 免责与对冲：延毕成因多元（学生自身、项目周期、制度性长学制）。呈现时强制附注"信号仅供参考"；允许导师侧**公开声明组规**（如"本组硕/博均为 4 年制"），声明置顶展示。

## 四、元字段（每条评价）

| 字段 | 说明 |
|------|------|
| `school_cate` / `university` / `department` / `supervisor` | 沿用前人 schema，便于历史数据导入工具复用 |
| `rate` | 总分 1–5（仅作参考，主呈现为维度分与硬信号） |
| `date` | 评价时间（时间衰减权重用） |
| `tenure` | 评价者与导师接触时段（如 2021–2024），防"道听途说"混入 |
| `identity_proof` | 匿名学院验证凭据（脱敏，参考 mysupervisor_save 建议） |
| `ai_generated_check` | AI 生成检测标记（GPT 刷评防护，v0.2 细化） |

## 五、总评呈现原则

1. **不做单一裸分排名**——呈现维度雷达 + 硬信号 + 时间衰减后的分布；
2. 老评价（>N 年）默认折叠，点击警告后展开；
3. 评价可被赞/踩，被踩阈值触发复核；
4. 作者本人可修改/删除自己的评价（出口设计，减少气话与诉讼）。
