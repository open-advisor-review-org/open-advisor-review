# 导师评分卡设计 v0（2026-10-02）

> 状态：试点版。数据源=评价库（merged/reviews.json 39,739 条，词表归一）+ 全网细化调研（advisor-research 流程）。
> 用户要求（2026-10-02）：**实习放行与学生退学作为额外评分项**。

## 一、九项评分

| # | 项 | 来源 | 分值 |
|---|---|---|---|
| 1-6 | academics 学术水平 / funding 经费 / stipend 补助 / relationship 师生关系 / workload 工作时间 / outcome 学生前途 | 评价 dims 模板词表归一（`score_advisors.py` DIM 映射）；"不清楚"类跳过 | 1-5 |
| 7 | rate 参考分 | 评价 rate 字段均值（71% 覆盖） | 1-5，独立呈现不进七维 |
| 8 | **internship 实习放行** | outcome/relationship 维实习词 + description_raw 正则（允许/不允许实习等）；**名义放行但横向项目多实际走不开 → 下调 1 档**（用户 2026-10-02 补充） | 正例≥2 且>2×负例=5；正>负=4；负≥2 且>2×正=1；负>正=2；混合=3；无证据=None |
| 10 | **direction_outlook 方向前途**（用户 2026-10-02 追加+定调） | **AI 评分**：锚点表 v2.1（AI 学生视角）——传统优化≤2 / 传统 ML≤2.5 / CV·NLP 经典任务=3 / LLM 相关=3.5 / 其他按四因子；四因子=学术热度/产业需求/斜率/5年可持续，另加 **fit 因子（导师近 5 年文章与领域主赛道贴合度：高不调/中 -0.5/低 -1.0）**；详见 `pilot_direction_scores.json` `_rubric` | 1-5，标注"AI 判断非客观测量" |
| 9 | **dropout_risk 退学风险** | description_raw 正则（退学/劝退/延毕/延期毕业/转导师/换导师/转组/休学/跑路/毕不了业） | 有"退学/劝退"提及即硬 flag；分数：无提及=None（不参与）；仅延毕类 1-2 次=3；退学/劝退提及 1-2 次=2；≥3 次或多条独立来源=1 |

- **退学 flag 呈现纪律**：显示"评价提及 N 次（关键词分布）+ 是否多源独立"，标注"未经证实的网络评价"；不得写个案姓名。
- **综合分** = 七维均值 0.55 + 实习 0.15 + 退学 0.15 + 方向前途(AI) 0.15（缺项权重重归一化；与 rate 7:3 融合做对照值）。总分旁必须带评数 n 与时间跨度。
- **负分制（用户 2026-10-02：本项目允许负分）**：综合分基础上叠加红线惩罚——不放实习/严重受限（internship≤2）**-2**；退学硬 flag **-3**；**两者同时触发合计 -6**（1-5 的 base 必穿负）。全库实测 505 人负分（双触发 41）。七维分保持 1-5 不变，只有综合分可负；负分卡必须在分值旁标注"红线惩罚"及触发项。

**权威数据源纪律**（用户 2026-10-02 要求）：论文数/引用/h-index/产出速率等学术指标，只接受 DBLP、Semantic Scholar、OpenReview、Google Scholar、官方院系页、NSFC 官方公示——不可溯源的聚合站数据不得用于评分，至多作风评线索。

## 二、呈现原则（沿用 dimensions.md 第五节）

1. 不做单一裸分排名——每卡呈现九项明细+证据数+时间衰减说明；
2. 评价 <3 条的导师不出综合分，只出维度原始引用；
3. 退学/实习信号单列"硬信号"区，带"未经证实"标注；
4. 全网调研证据与库内评价冲突时并列呈现，不仲裁。

## 三、试点（2026-10-02，6 位）

选样逻辑：评数 ≥13 且 matched，覆盖四种形态——正面基线（卢湖川 4.15）、负面典型（张智军 2.58/24 评）、退学延毕硬 flag（陈岭 2.72 延毕×6、郭霞 2.67 退学×3）、高学术低体验分裂（刘涛 2.86 academics 5.0 但 rate 1.75）、实习负信号（宋爱波 3.51 负 5 条）。

管线：`score_advisors.py`（全库 17,333 导师 → `advisor_scores.json`）；全网调研 `data/scores_pilot/*.md`（2 个调研代理，advisor-research 六步+实习退学专项）；合成 `data/scores_pilot/scorecards_20261002.md`。
