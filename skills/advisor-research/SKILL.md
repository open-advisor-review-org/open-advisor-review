# 导师调研（advisor-research）

**原则**：只用公开可验证的信息源；每条结论必须标注来源 URL；查不到就写"未找到"，**禁止编造与脑补**；涉及负面风评时呈现原文并注明"未经证实的网络评价"。

## 输入

必填：导师姓名、学校（学院可选）。若同名，先做消歧（研究方向交叉比对），向用户确认。

## 调研步骤（按序执行）

### 1. 官方信息基线
- 学校/学院官网导师主页：职称、方向、招生资格（博导/硕导）、联系方式
- 教育经历与工作经历（判断：青年帽/海外背景/工业界经历）

### 2. 学术产出画像（AI 学科重点）
- **DBLP / OpenReview / Semantic Scholar / Google Scholar**：近 5 年产出速率、发表去向（NeurIPS/CVPR/ICLR/ACL/AAAI vs 低质灌水 venue）、是否持续有主线方向
- 关键信号：**学生一作比例**（导师通讯 vs 一作占比）、组内学生姓名是否反复出现在好工作上
- **GitHub**：是否有实验室组织账号、开源项目活跃度（AI 学科特有信号）

### 3. 经费与项目
- 国家自然科学基金（NSFC，可查 letpub 等）：在研/结题项目、金额、年限
- 缺经费信号：长期无在研项目

### 4. 学生流向硬信号（最重要的预警维度）
- 研究生院**毕业公示/学位授予名单** vs 历年**招生名单/拟录取名单**：估算实际毕业缺口
- 导师主页"在读学生/毕业生"名单的年份变动
- 公开报道中的退学/延毕/师德通报（学校纪委、教育部通报）

### 5. 网络风评（需标注未经证实）
- 知乎/小红书/一亩三分地等提及（原文引用 + 时间 + 链接）
- 注意区分：本人回应、时间久远的旧评价、单一来源孤证
- **登录态机制（实验性）**：平台搜索需登录时，由用户主动提供自己的手机号并当场输入验证码，用浏览器登录**用户本人账号**只读搜索；凭证不落盘、任务结束退出登录、只读不互动、不采集他人资料（与 `advisor-roster` 的 L3 规则一致）

### 6. 同层级对照（可选，用户要求时）
- 找同院 2–3 位同方向导师做横向对比表

## 输出格式

```markdown
# {导师姓名}（{学校} {学院}）调研报告
> 生成时间 / 信息截止时间 / 数据来源数

## 摘要（3 句以内，只说可验证的事实）
## 基本信息 | ## 学术产出画像 | ## 经费项目
## 学生流向信号（列出名单比对结果与缺口估算，注明估算方法）
## 网络风评（每条：原文摘录 + 来源链接 + 时间 + "未经证实"标注）
## 信息缺口（哪些维度查不到公开数据——建议直接联系在读学生求证）
```

## 红线

- 不输出"建议报/不建议报"的最终裁决，只呈现证据与信号
- 不使用任何泄露的个人隐私信息（学生姓名名单仅用于计数，不写入报告正文）
- 涉及师德通报等严重指控：仅链接官方来源，不复述细节、不添加推断

## 新鲜度纪律（强制，用户 2026-10-02 要求）

- 报告头部必带**信息截止时间**（最后一条成功抓取的时间）；每条证据带日期，无日期标"日期不明"
- 学术画像窗口=近 5 年；风评优先近 3 年，更早的标"[旧评]"；官方页面带页面更新日期或抓取日期
- 产出文件名含日期（YYYYMMDD），重跑覆盖前先归档
- 联网请求失败重试 2 次后跳过并留痕，不阻塞整份报告
